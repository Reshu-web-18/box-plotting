# 📦 CSS Box Model

A simple HTML and CSS project that demonstrates the CSS Box Model. It visually explains the four main parts of the box model: Margin, Border, Padding, and Content.

## 📌 Features

- Visual representation of the CSS Box Model
- Clearly labeled Margin, Border, Padding, and Content
- Simple and easy-to-understand design
- Centered layout using Flexbox

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📂 Project Structure

```
CSS-Box-Model/
│── index.html
│── README.md
```

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in any web browser.

## 📚 Concepts Used

- CSS Box Model
- Margin
- Border
- Padding
- Content Area
- Flexbox
- Positioning

## 📸 Output

The webpage displays a visual representation of the CSS Box Model with:
- Margin
- Border
- Padding
- Content

This helps beginners understand how spacing works in CSS.
